Abuse, removal and security reports

Use this page to ask us not to check your website, to remove records about it, to report misuse of Sentinel, or to report a security problem in Sentinel itself.

How Sentinel checks a site

  • Checks are started by a person pasting an address. Sentinel is not a crawler.
  • It makes one GET request to that page and one request to the http:// version to test the redirect. It follows at most three redirects.
  • It identifies itself as Sentinel/1.1 (+https://sentinel.kejanigarage.com/abuse).
  • It is limited to 8 checks per minute per visitor. It does not log in, submit forms or send exploit code.

What happens after you send a report

  • Opt-out: We verify that you control the domain (for example by replying from an address at that domain, or asking you to add a DNS TXT record), then block it. Subdomains are covered.
  • Removal: After the same verification we delete stored check records for that domain.
  • Abuse: We look into it, block offenders if needed, and reply to you.
  • Security issue in Sentinel: Please give us reasonable time to fix it before sharing details publicly. See also security.txt.

We aim to reply within five working days.
