How to use and what results mean

How to use

  1. Enter site URL (and optional API URL).
  2. Click Check Now.
  3. Read status, headers, and next steps.
  4. Get a fix plan, or book a call if you want help.

Results

Vulnerable — affected PHP detected.

Hidden — PHP present, version private.

Safe — patched version signals.

No PHP — no clear PHP on this URL.

What Sentinel does and does not do

Sentinel reads only public information, the same as opening the page in a browser. It never logs in, never sends exploit code and checks one page per request. Results are indicators, not a security audit: some hosts backport fixes without changing the version number. If you own a site and do not want it checked, tell us.
