What exactly is PHP2Shell?

Two critical vulnerabilities in the PHP engine itself. Both allow unauthenticated remote code execution. Tracked as CVE-2026-109618 and CVE-2026-109619.

Which versions are safe?

  • PHP 8.5.12
  • PHP 8.4.27
  • PHP 8.3.36
  • PHP 8.2.35
