How to use and what results mean

How to use

  1. Enter a website URL.
  2. Click Check Now.
  3. Read the status and next step.
  4. Book a free call from the page if you want help.

What the results mean

Vulnerable — A PHP version known to be affected was detected. Upgrade is recommended.

Version Hidden — PHP is present, but the version is not public. Verify on the server.

Safe — The detected version includes the official patches for the CVEs this tool checks.

No PHP Detected — This URL did not show clear PHP signals. A separate API or backend may still use PHP.

What this tool checks

Public headers, common framework signals, PHP version when exposed, and whether that version is below the fixed releases for CVE-2026-109618 and CVE-2026-109619. It also reports other public technology signals when present.

What it does not do

It does not log into your server, run exploits, or guarantee visibility when versions are hidden. For non-PHP stacks it describes what public signals suggest; it is not a full vulnerability audit of every language.

Currently checked (PHP)
