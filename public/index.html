Guide

How to use it, and what results mean

How to use

  1. Enter a website URL.
  2. Click Check Now.
  3. Read the status and next step.
  4. Book a free call if you want help.

What results mean

Vulnerable — affected PHP version detected. Upgrade recommended.

Version Hidden — PHP present, version not public. Verify on server.

Safe — detected version includes official patches we check.

No PHP Detected — no clear PHP signals on this URL.

What this tool checks

Public headers, framework signals, PHP version when exposed, and whether it sits below fixed releases for CVE-2026-109618 and CVE-2026-109619. Other public tech signals when present.

What it does not do

No server login, no exploits, no guaranteed visibility when versions are hidden. Not a full multi-language vulnerability audit.
