1. What Sentinel is

Sentinel looks at the public signals a website gives out (response headers, the visible page, TLS basics) and reports what it finds, for example the reported PHP version, missing security headers and technology fingerprints. It can also generate a suggested fix plan. It is an awareness tool, not a security audit or penetration test.

2. How checks work

  • Sentinel sends ordinary GET requests to the address you enter, plus one request to the plain http:// version to see whether it redirects to https://. This is the same information a browser would receive.
  • It does not log in, guess passwords, crawl the site, or send exploit code.
  • Requests identify themselves with the user agent Sentinel/1.1 (+https://sentinel.kejanigarage.com/abuse).
  • We keep a list of sites whose owners asked not to be checked, and we honour it. See Abuse and removal.
